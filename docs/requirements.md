# 要件定義

## 目的

Graphiti にテキストを投入して時系列ナレッジグラフを構築し、質問に関連する情報を検索して回答とグラフで確認できるサンプルを提供する。

## 技術要件

- バックエンド: Python / FastAPI
- フロントエンド: Vite / Svelte
- ナレッジグラフ: Graphiti Core / Neo4j
- 起動: Docker Compose
- Graphiti の既定 LLM プロバイダーを利用し、`OPENAI_API_KEY` を環境変数から渡す。

## 機能要件

### チャット画面

- 質問を入力して送信できる。
- バックエンドは Graphiti の検索機能で関連情報を取得する。
- 検索結果を使った短い回答と、検索コンテキストのノード・関係を表示する。
- 画面は左側を会話、右側をグラフ表示とする。
- グラフは検索結果に含まれるエンティティと関係を描画する。ノード選択や編集は対象外。

### データ投入画面

- テキストを入力して送信できる。
- バックエンドはテキストを Graphiti のエピソードとして登録する。
- 登録完了を画面に表示する。

## 対象外

認証、権限管理、汎用エラーハンドリング、入力バリデーション、会話履歴の永続化、独自の LLM 推論・グラフ処理、複雑なアーキテクチャは実装しない。
